## 📖 项目简介

广州市中小学教师继续教育网（gzteacher.com）及其合作机构的课程学习流程高度重复：打开课程 → 点击学习 → 弹「继续学习」→ 看视频 → 中途弹题 → 关掉弹窗 → 返回列表 → 等进度刷新 → 下一门……一学期几十门，纯手工操作费时费力。

**AutoDone** 把这些固定步骤交给浏览器脚本自动完成：自动识别未完成课程并进入学习，视频自动播放（切后台/最小化不中断），弹出的题目自动识别作答，学完自动返回列表、同步进度、开下一门，全部跑完后自动收尾核对补刷。

## ✨ 功能特性

| 特性 | 说明 |
|---|---|
| 🎯 **自动识别未完成课程** | 打开学习中心自动扫描课程列表，自行进入未完成的课程 |
| ▶️ **视频自动播放** | 倍速播放 + 播放守护，切后台 / 最小化 / 切标签页都在跑 |
| 📝 **弹题自动作答** | 学习过程中弹出的题目自动识别并作答 |
| 🔁 **自动连播与课程切换** | 学完自动返回列表、同步进度、自动开下一门，循环直到全部学完 |
| 🔍 **收尾核对自动补刷** | 全部课程跑完后自动复核，漏掉的可自动任务自动补刷 |
| 💾 **断点恢复** | 处理过的课程不重复进；断网 / 刷新 / 浏览器重启后自动恢复重试 |
| 🛡️ **会话过期守卫** | 登录态失效自动检测并提醒，不会卡死空转 |
| 🤝 **人机协作兜底** | 自动化搞不定的场景（互动研讨、发帖、作业等）自动汇总提示人工处理，不瞎点不乱跑 |
| 🚧 **未适配平台保护** | 脚本暂未适配的机构课程自动跳过并提示，不会误跑乱点 |
| 🎛️ **悬浮控制面板** | 随时开始 / 暂停 / 查看日志，不用时折叠成小药丸挂角落 |
| ☁️ **云端加密规则下发** | 选择器 / 关键词 / 阈值全部云端加密下发，平台悄悄改版也不用追着改脚本 |

## 🚀 快速开始

### 1. 安装油猴插件（Tampermonkey）

浏览器扩展商店搜索 **Tampermonkey** 安装（Chrome / Edge / Firefox 均支持）。

> Chrome MV3 用户注意：安装后需到 `chrome://extensions` → Tampermonkey → **详情** → 手动打开「**允许运行用户脚本**」，否则脚本无法注入。

### 2. 🔴 下载发行版（运行必须用发行版，不要用 src/ 里的源码）

前往本仓库 **[Releases](../../releases)** 页面，下载最新版 Release 附件 `gzteacher-autolearn.user.js`，拖入浏览器或粘贴到油猴「安装新脚本」完成安装。

> **为什么运行必须用 Release 版（或仓库根目录的同名发行版）？**
> 1. 发行版经过**完整性校验登记**：脚本运行时会自算校验值并与后台登记版本对账。被改动、不完整或非发行版的脚本文本会触发「脚本被改动」提示，**无法通过授权正常运行**；
> 2. `src/` 目录里是**开发版源码**（带完整注释），其中的完整性自检哨兵未替换、构建号与后台登记不一致，**仅供查阅学习，不可直接安装运行**；
> 3. 从其他渠道（群聊转发、网页复制、旧版备份）获得的脚本文本同样可能被改动或不完整，请勿使用。

### 3. 登录并授权

1. 打开并登录广州中小学教师继续教育网（www.gzteacher.com）
2. 首次使用需要**学习卡授权**（一卡一期，试用期免费额度用完后绑定）：
   - 打开脚本主页 [https://www.autodone.top](https://www.autodone.top) 了解学习卡获取方式
   - 已登录继教网的状态下，脚本会自动完成账户注册；打开油猴菜单 →「🔑 授权面板」绑定学习卡
3. 进入学习中心，脚本自动开始工作；悬浮面板可随时暂停 / 继续 / 查看日志
